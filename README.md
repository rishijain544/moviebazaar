# moviebazaar

A simple movie showcase website built with a single HTML file and local poster images.

## Run locally

1. Open `index.html` in your browser.
2. The page uses local images in the same folder, so no server is required.

## GitHub Pages

If you enable GitHub Pages for this repository, the site will serve from `index.html` automatically.

## Files included

- `index.html`
- `movie.html`
- Movie poster image files

Enjoy the site!
